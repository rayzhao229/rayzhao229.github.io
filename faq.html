常见问题

买家最常问的问题。没有找到答案？直接联系我们，我们会在一个工作日内回复。

你们主要供应哪些产品？

我们是综合贸易公司，品类不设限。口罩与防护用品（口罩用无纺布/熔喷材料、N95 与 FFP3 成品口罩、防护服与隔离衣、口罩机与熔喷生产线）、断路器与低压电气元件、铸造件（铁 / 钢 / 不锈钢 / 铝）、HDPE 高密度聚乙烯塑料制品与起重机械索具，是我们长期稳定供货的五条重点产品线；此外机电、建材、五金工具、包装、劳保、日用工业品等工业品全品类均可承接采购委托。重点品类可单独采购，不同品类之间也可拼柜发运。

可以先寄样品吗？

可以。对需要确认材质、规格或配合尺寸的货品，我们会先安排样品寄送。样品费用是否可在后续批量订单中抵扣，属于可协商项，需在商务沟通时单独确认。

网站上没列的品类，你们也能做吗？

能。我们是综合贸易公司，承接的是工业品全品类的采购与供应链委托，而不是只做网站列出的几类。列出这五条重点产品线，是因为它们我们长期稳定供货、熟悉规格与验货标准。其他品类同样接单：机电、建材、五金工具、包装、劳保、日用工业品等，给出规格、数量与目的地即可，我们负责找厂、比价、验货、拼柜发运与单据跟进。

你们能提供 CE / ISO 等认证和第三方验货吗？

可以按需安排，但不是所有品类都自带。实际做法是：报价阶段我们会把该品类能提供的文件清单（材质证明、出厂检验报告、CE / ISO 等适用证书）随报价一起发给你确认；第三方验货（SGS 等）我们可以代为安排，属于需额外确认的付费服务。具体哪些文件能随货提供，以对应工厂与这笔订单为准。

可以拼柜发货吗？一次能发多少？

可以。不同品类可以合并装到同一柜内，我们会按体积与重量核算装柜方案，并给出运费拆分参考。走整柜还是拼箱（LCL），取决于订单量与目的港；单笔货量装不满整柜时，我们按拼箱方案报价，货物会按品类分箱贴唛，便于清点与分拨。

能按我们的规格或图纸做 OEM / 贴牌吗？

可以。我们承接的是采购与供应链委托，定制类需求会转给对应工厂按图或按样生产。常规流程是：你提供图纸、样品或性能要求，我们反馈工厂能否做到、所需起订量与打样周期，以及材料证明与检验如何安排。定制件需要排产，交期以工厂确认后的排期为准，我们不会先承诺一个做不到的日期。

可以提供成品口罩（N95 / FFP3）和口罩机吗？

可以。成品口罩我们能供 N95、FFP3 等等级，医用与民用两种口径都做过，平口、折叠、带阀等款式，可做 OEM 贴牌与出口包装；对应的检测与注册文件按工厂实际可提供的清单随报价列明。防护服方面可供一次性防护服、隔离衣、手术衣等 PPE 防护服装，材质按用途选。口罩机方面可提供平面口罩机、折叠口罩机与熔喷生产线，按你的目标产能与自动化程度做选型，含发货、安装调试与操作培训支持。若你打算在本地建口罩厂，把目标产能、产品型式与投产时间告诉我们，材料 + 成品 + 设备 + 防护用品可以一起给方案。

最小起订量是多少？

起订量按品类、规格与工厂排产情况而定。常规规格的口罩用无纺布、HDPE 管件与断路器等通常可以接受较小的试单量；铸造件与定制件因需排产，起订量会相应提高。请把预计数量发给我们，我们按量级给出方案与具体起订量。

支持哪些贸易与付款条款？

常用条款包括 EXW、FOB、CIF 与 DDP，具体按订单协商确定。付款方式可按合作阶段与金额商定，常见做法是先付定金、验收后付尾款再安排发运，具体以双方确认的订单条款为准。

从下单到收货大概要多久？

取决于品类、数量与定制程度：常规货品按库存与备货周期安排，需要排产的定制件按工厂产线排期，海运时效另按航线与目的港计算。准确交期我们会在报价单中随价格一并给出——排产类订单的交期以工厂确认后的排期为准。

能提供质检报告和材质证明吗？

可以。标准出货随附装箱单与箱唛等基本装运单据；铸件与电气元件可按需提供材质证明。第三方验货可代为安排，属于需额外确认的付费服务。具体的文件清单与费用，我们在下单前逐项写清楚。

你们有没有做过出口？

我们的客户以国内企业采购为主，同时也服务海湾地区（沙特、阿联酋等）的采购方，可协助安排拼柜与采购对接。出口方式、单据安排与费用构成，我们会在报价阶段一并说明，不做口头承诺。
